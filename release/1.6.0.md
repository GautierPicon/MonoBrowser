## What's new in 1.6.0

### Downloads

- Clicking a link to a PDF, a `.zip`, a `.dmg` or any other download no longer does nothing — it downloads
- Files are saved to `~/Downloads`; if the name is taken, a number is appended (`report (1).pdf`)
- A small toast in the bottom-right corner shows the file name, progress in MB and a thin progress bar
- While the download runs, a button cancels it; once it finishes, a button reveals the file in Finder and the toast dismisses itself after a few seconds
- Failures (no space, interrupted connection…) are reported in the toast with the reason
- The UI never freezes — downloads run off the UI thread

### History

- Browsing history is now persisted across restarts (the 100 most recent pages)
- Burger menu → **History** (or `about:history` in the address bar) shows the page: title, URL, favicon and time
- A search field filters the list as you type
- Hover an entry to remove it individually; **Clear history** wipes everything (with confirmation)
- About pages are re-rendered on reload instead of showing a stale copy

### Picture in picture

- The tab stays alive behind the PiP window: a dimmed snapshot of the page stays visible instead of a blank area, and media keeps playing
- New control bar in the PiP window: back to page, minimize, play/pause, and a seekable progress bar
- Video detection is more reliable on complex pages (open shadow DOM, cross-origin iframes)

### Fixes

- Fixed a crash at launch caused by stale icon references after the icon reorganization
- Fixed a crash in Settings when the cosmetic ad-blocking row is not rendered
- Moving a tab no longer loses its muted/audible state

### Under the hood

- QSettings is no longer constructed on every network request; icons and about pages are cached
- Internal reorganization (split of the QML chrome into components) — no user-visible change

## Installation

1. Download the `MonoBrowser-1.6.0-macOS-arm64.zip` attached below
2. Unzip and drag `MonoBrowser.app` to `/Applications`
3. Launch it

> [!WARNING]
> The app is not code-signed (no Apple Developer account yet). On first launch macOS may refuse to open it ("developer cannot be verified"). Workaround: right-click → Open, or run `xattr -cr /Applications/MonoBrowser.app`.

## Requirements

- macOS on Apple Silicon
- No Python installation needed, everything is bundled
