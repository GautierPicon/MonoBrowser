## What's new in 1.7.0

### Address bar

- Start typing and the address bar now shows matching pages from your browsing history below the field — title and URL, most relevant and most recent first
- `↑`/`↓` move through matches, `Tab` completes the text without navigating, `Enter` opens the selected page, `Escape` dismisses the list and restores what you typed
- With DuckDuckGo selected as the search engine, suggestions from DuckDuckGo appear in a second section below the local matches
- Suggestions are debounced, fail silently offline, and never trigger a navigation until you press `Enter`
- Local matches keep working even if you turn search suggestions off

### Ad blocking

- The network blocker now uses **EasyList + EasyPrivacy** instead of a hosts file: about 94 000 domains, with `@@` exceptions, `$third-party` and `$domain=` rules
- The **Hide ad elements (CSS)** switch is unchanged and still uses the built-in selector list
- The bundled lists are a static snapshot; `README.md` has the two `curl` commands to refresh them

### Privacy

- New **Settings → Privacy** section with two switches
- **Send anti-tracking signals** (on by default) sends `DNT: 1` and `Sec-GPC: 1` with web requests. These are requests to sites, not a tracker blocker, and they do not interact with the ad-blocking counter
- **Address bar suggestions** (on by default) sends what you type to DuckDuckGo so suggestions can be shown. Turn it off to stop those requests entirely; local history matches keep working. No suggestion requests are sent when Google is selected

### External links

- `mailto:`, `magnet:`, `webcal:`, `slack://`, `tel:` and other registered schemes now open in the corresponding system application, whether you click a link or type the URL yourself
- The current tab stays on its page; unregistered schemes are silently ignored instead of replacing it with an error page
- Typed `file://` URLs still work, and remote pages still cannot navigate to local files
- `ftp://` is no longer treated as a web URL; it is handed to the system like other external schemes

### Under the hood

- The request interceptor now also injects the privacy headers, before the ad-blocking check, so they are sent even when ad blocking is off
- Web-engine navigation requests are vetted before commit, with the scheme allowlist living in one place
- Nothing is logged about what you type; failed or cancelled network requests are discarded without dialogs

## Installation

1. Download the `MonoBrowser-1.7.0-macOS-arm64.zip` attached below
2. Unzip and drag `MonoBrowser.app` to `/Applications`
3. Launch it

> [!WARNING]
> The app is not code-signed (no Apple Developer account yet). On first launch macOS may refuse to open it ("developer cannot be verified"). Workaround: right-click → Open, or run `xattr -cr /Applications/MonoBrowser.app`.

## Requirements

- macOS on Apple Silicon
- No Python installation needed, everything is bundled
