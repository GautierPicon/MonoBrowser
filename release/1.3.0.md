## What's new in 1.3.0

The whole interface was rebuilt on Qt Quick/QML and now sits on a real macOS window.

### A native macOS window

- The real traffic lights live in the tab strip, in a single unified titlebar
- Native resize borders, shadow and rounded corners
- One shared theme, so the chrome follows macOS light/dark mode automatically
- All icons are SVG drawn in `currentColor`: crisp on Retina, theme-aware

### Picture in picture

- Float a playing video in a small always-on-top window: the toolbar button that
  appears while a video plays, the menu entry, or `⌘⇧P`
- Works with videos embedded in cross-origin iframes; the window follows the video
  and exits when it disappears or ends

### Chrome

- The burger menu and the right-click page menu are now macOS-style popovers
  (translucent rounded background, shadow, accent hover, right-aligned shortcuts)
- HTTPS indicator in the address field, including rejected certificates
- The address is shown without its scheme and leading `www.` until you focus it
- Hovering a link previews its target at the bottom of the window
- `chrome://` addresses are no longer sent to the search engine

### Performance

- Background tabs are frozen and only the visible one stays active (audible tabs
  keep playing and are frozen once the audio stops)
- Tab views are created from a single declared component instead of reparsing QML
  on every new tab
- Lighter tab-model, progress-bar and about-page updates

### Fixes

- The address field is now sized by the layout instead of a fixed width
- Closing a background tab no longer moves away from the current tab
- A tab that cannot create its view is aborted cleanly
- `⌃C` quits a dev run from the terminal

## Installation

1. Download the `MonoBrowser-1.3.0-macOS-arm64.zip` attached below
2. Unzip and drag `MonoBrowser.app` to `/Applications`
3. Launch it

> [!WARNING]
> The app is not code-signed (no Apple Developer account yet). On first launch macOS may refuse to open it ("developer cannot be verified"). Workaround: right-click → Open, or run `xattr -cr /Applications/MonoBrowser.app`.

## Requirements

- macOS on Apple Silicon
- No Python installation needed, everything is bundled
