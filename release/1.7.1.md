## What's new in 1.7.1

### Settings

- Every setting now uses the same row layout and the same control style: switches for on/off options, segmented buttons for mutually exclusive choices
- **Restore previous session** is a switch like the other booleans
- Google and DuckDuckGo have their logos in the search-engine buttons
- Fixed the appearance icons being hard to read on the blue selected button

### Address bar

- The popup now starts with a row that searches (or opens) exactly what you typed. It is selected by default — press `Enter` immediately, or use `↓` to browse the other suggestions
- MonoBrowser now tells apart a URL from a search query: when your text looks like a URL (or matches a host from your history), only matching URLs are shown and no DuckDuckGo request is sent
- History matches are marked as coming from the page title or the URL, so the right ones are shown for each case

### Ad blocking

- New **Use EasyList element rules** switch in Settings → Ad blocking. When enabled, site-specific `##` rules from EasyList are added to the built-in CSS selectors that hide ad containers
- Generic rules, procedural selectors and `#@#` exceptions are handled conservatively: generic and procedural rules are ignored, exceptions are honoured

## Installation

1. Download the `MonoBrowser-1.7.1-macOS-arm64.zip` attached below
2. Unzip and drag `MonoBrowser.app` to `/Applications`
3. Launch it

> [!WARNING]
> The app is not code-signed (no Apple Developer account yet). On first launch macOS may refuse to open it ("developer cannot be verified"). Workaround: right-click → Open, or run `xattr -cr /Applications/MonoBrowser.app`.

## Requirements

- macOS on Apple Silicon
- No Python installation needed, everything is bundled
