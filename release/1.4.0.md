## What's new in 1.4.0

### Find in page

- `⌘F` opens a find bar at the top right of the page, like the usual macOS pattern
- Case-sensitive toggle, previous/next buttons and a live `n/m` counter fed by the web engine
- `Enter` / `Shift+Enter` steps through matches; `Escape` dismisses the bar, clears the highlight
  and hands focus back to the page

### Pages that fail to load

- A failed load no longer leaves a blank tab: a local error page shows the attempted URL, the
  reason and a Retry button
- Certificate errors get the same treatment instead of being silently rejected into oblivion

### Zoom

- Per-tab zoom with `⌘+` / `⌘−` / `⌘0`, kept with the tab for the whole session
- A transient HUD shows the current scale while you zoom

### Closed tabs

- `⌘⇧T` reopens the most recently closed tab — title, URL and favicon restored at its original
  position; repeated presses walk back through the stack
- Also available in the burger menu as "Reopen Closed Tab" when there is something to reopen

### Keyboard shortcuts

- `⌘⌥←` / `⌘⌥→` switch to the previous/next tab (wrapping around); `⌘⇧[` / `⌘⇧]` still work too
- Zoom, find in page and reopen closed tab now have the shortcuts you would expect
- The complete shortcut list is documented on the About MonoBrowser page

### Tab strip

- Tabs shrink before they overflow; when they still don't fit, the strip scrolls with the mouse
  wheel (the wheel never triggers tab switching)
- Middle-click on a tab closes it; hovering a tab shows a tooltip with its title and URL
- A spinner shows in the favicon slot while the tab loads; sites without an icon show a globe
  instead of an empty slot — the slot no longer jumps
- Drag a tab to reorder it; an insertion bar shows where it will land

### Fixes

- Pop-ups, `target=_blank` links and "View page source" now open in a new tab; Qt 6 removed the
  `openInWebEngineView()` call the app relied on, so those requests were silently dropped

## Installation

1. Download the `MonoBrowser-1.4.0-macOS-arm64.zip` attached below
2. Unzip and drag `MonoBrowser.app` to `/Applications`
3. Launch it

> [!WARNING]
> The app is not code-signed (no Apple Developer account yet). On first launch macOS may refuse to open it ("developer cannot be verified"). Workaround: right-click → Open, or run `xattr -cr /Applications/MonoBrowser.app`.

## Requirements

- macOS on Apple Silicon
- No Python installation needed, everything is bundled
