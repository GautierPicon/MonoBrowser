## What's new in 1.2.0

- Keyboard shortcuts (new tab, focus URL bar, close tab, reload, stop, switch with Cmd/Ctrl+1–9)
- URL bar hint text (placeholder like in HTML, no more manual clearing)
- Fixed background tabs overwriting the current tab's title
- Fixed favicons sticking after navigation
- Removed the dead duplicate new-tab button in the tab bar
- Closed tabs are now properly destroyed

## Installation

1. Download the `MonoBrowser-*-macOS-arm64.zip` attached below
2. Unzip and drag `MonoBrowser.app` to `/Applications`
3. Launch it

> [!WARNING]
> The app is not code-signed (no Apple Developer account yet). On first launch macOS may refuse to open it ("developer cannot be verified"). Workaround: right-click → Open, or run `xattr -cr /Applications/MonoBrowser.app`.

## Requirements

- macOS on Apple Silicon
- No Python installation needed, everything is bundled
